Deadlock Vaccination rethinks deadlock handling as a proactive problem instead of a reactive one. The system analyzes a process resource manifest before execution, injects prevention rules up front, and uses graph-based cycle detection to keep deadlocks from emerging in the first place. The project also includes a real-time animated GUI and benchmarking work showing meaningful throughput and overhead improvements over reactive approaches.

GitHub: [Deadlock-Vaccination](https://github.com/rushabu/Deadlock-Vaccination)
