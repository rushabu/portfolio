This project applies computer vision to satellite and aerial imagery for automated change detection and structured report generation. It focuses on identifying deforestation, urban expansion, and land-use shifts from time-series image pairs, then summarizing those findings with supporting visual evidence. It is a practical mix of image processing, geospatial reasoning, and automated reporting.
