Class-AI is a production-grade RAG system built for NMIMS MPSTME as an institutional knowledge assistant. It uses hybrid retrieval with dense embeddings, BM25 sparse retrieval, and cross-encoder reranking over a Qdrant vector database, paired with a FastAPI backend, real-time streaming responses, caching, rate limiting, and Docker Compose orchestration. The result is a deployed, versioned system designed for real academic use rather than a simple prototype.
