Tutor is a multi-tool study application built with local LLMs using Ollama and LangChain so it can work privately and offline. It bundles conversational study support, PDF chat, website chat, text-to-speech, and task management into a single student-focused system. It is an important project in the portfolio because it shows a clear product direction while also laying the groundwork for later RAG-heavy systems.

GitHub: [Tutor](https://github.com/rushabu/Tutor)
