Neuropath is an adaptive onboarding engine that compares a resume against a job description, extracts and semantically normalizes skills, and then generates a personalized learning path. It uses Gemma 3 for extraction, sentence transformers for semantic matching, and an interactive graph-based interface for learning path visualization. The stack spans Flask, Next.js, Tailwind, and Docker Compose, making it both technically ambitious and product-oriented.

GitHub: [Neuropath](https://github.com/rushabu/Neuropath)
