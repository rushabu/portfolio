This project benchmarks four different NLP vectorization strategies on the Steam games dataset to compare recommendation quality in a content-based recommendation setting. Rather than stopping at a single implementation, it evaluates CountVectorizer, TF-IDF, HashingVectorizer, and GloVe embeddings side by side, turning the project into both a working recommender and a documented empirical study.

GitHub: [Game-Recommendation-System](https://github.com/rushabu/Game-Recommendation-System)
